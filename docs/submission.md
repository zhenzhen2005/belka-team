## 01 · ปัญหา · Problem

**Motion Story: เห็น → เข้าใจ → เชื่อ → คลิก** (PROBLEM → HELP → SHIFT → ACTION)

SME ไทยเจอ **"ต้นทุนบีบรายได้"** — ดัชนีรายได้ Q2/2568 **ลด 1.11%** ขณะต้นทุน **เพิ่ม 4.16%** · ภาคผลิตหนี้เสีย **28%** [source: participant]

ทำไมร้านขายของเหมือนกัน บางร้านแมส บางร้านเงียบ? จุดต่างไม่ใช่ "ของไม่ดี" แต่คือ **การตลาด** — ร้านเล็กแพ้เพราะทำการตลาดสู้ร้านแมสไม่ได้ จากสัมภาษณ์ **8 ร้าน** ใน กทม./นนทบุรี ปัญหาหลักคือ **"ไม่รู้ว่าจะทำการตลาดอย่างไร"** [source: user interview]

- ❓ **คอนเทนต์** — ไม่รู้จะสร้างอะไรดึงลูกค้า
- 📡 **ช่องทาง** — ไม่รู้ควรใช้ช่องทางไหน
- 🕒 **เวลา** — ไม่รู้ควรโพสต์เมื่อไร/บ่อยแค่ไหน
- ✍️ **ทักษะ** — เขียนแคปชัน/ทำสื่อไม่เป็น
- ⏳ **เวลาน้อย** — วางแผนให้ทำได้จริงไม่ได้
- 🤝 **ความไว้ใจ** — กลัวดูเหมือนหลอกลูกค้า

_Source: user interview (8 shops, Bangkok & Nonthaburi)_

## 02 · ภาพรวม · Overview

ในภาวะที่ SME ไทยเจอ "ต้นทุนบีบรายได้" (ยอดขายลด ต้นทุนเพิ่ม กำไรหด) Belka คือผู้ช่วยการตลาด AI บนมือถือ ที่โจมตี**ฝั่งรายได้**—คันโยกเดียวที่ร้านคุมเองได้—ส่ง**แผนรายสัปดาห์พร้อมใช้** ให้เจ้าของร้านที่ไม่มีความรู้ ทีม หรืองบการตลาด [source: participant]

- 🏪 **Pillar:** SME & Local Economy
- 🎯 **กลุ่มแรก:** ร้านอาหาร เบเกอรี่ เครื่องดื่ม
- ⏱️ **เวลาที่ใช้:** ~10 นาที/วัน
- 🐿️ **Tagline:** เพื่อนคู่คิด SME

⭐ **จุดต่างจากคู่แข่ง (นกกระซิบ, Grab/LINE MAN Merchant):** แผนพร้อมใช้ + AI chatbot "ถาม Belka" (Amazon Quick) + explainability "ทำไมต้องทำ?" + guardrail การตลาดซื่อสัตย์ [source: participant]

## 03 · วิธีแก้ · Solution (2 ฝั่ง)

**ขั้นตอนการทำงาน 5 สเต็ป:**
1. **เข้าใจร้าน** — การ์ดแตะเลือก ไม่บังคับกรอกต้นทุน
2. **ลูกค้าจำลอง** — persona ติดป้าย "Simulated"
3. **แผนพร้อมใช้** — อะไร/ทำไม/ช่องทาง/เมื่อไร + แคปชัน
4. **เลือกช่องทาง** — ให้เหมาะกับร้าน
5. **วัดผล & ปรับ** — measured vs predicted

**📈 ฝั่งเพิ่มรายได้:** แผนพร้อมใช้ + "ถาม Belka" (Amazon Quick) + "ทำไมต้องทำ?" + ดันช่องทางที่ร้านเป็นเจ้าของเอง (LINE/เพจ)

**💰 ฝั่งลดต้นทุน:** ตัดค่าเอเจนซี่ (฿15,000–150,000→฿150–1,000) · ลดพึ่งแพลตฟอร์ม GP สูง · คำนวณกำไรจริงต่อเมนูแยกช่องทาง (หัก GP อัตโนมัติ) + เตือนเมนูขาดทุน + แนะนำงบการตลาดจาก GP ที่ประหยัดได้

🧮 **กรอกต้นทุนแบบง่ายสุด (ออปชัน 3 ระดับ):** ① แตะเลือกช่วงกำไร 🟢🟡🔴 · ② กรอกต้นทุนวัตถุดิบ 1 ช่องต่อเมนู (GP ระบบหักให้ตามช่องทาง) · ③ ใช้ค่ามาตรฐาน F&B (ติดป้าย 'ค่าประมาณ — แก้ได้')

**หลักการ:** ใช้ง่ายแม้ไม่มีความรู้ · เริ่มได้โดยไม่ต้องกรอกต้นทุน · ให้คอนเทนต์พร้อมใช้ · สื่อสารซื่อสัตย์ ไม่โอ้อวดเกินจริง [source: participant]

## ★ · ทำไม Belka ชนะ · Why We Win (Judging Criteria: Idea)

ตอบโจทย์เกณฑ์ตัดสินฝั่ง Idea ครบทั้ง 5 ข้อ + จุดแข็งด้านต้นทุน — ทุกข้อมีหลักฐานจริงหนุน:

1. **💡 Novelty & Originality (vs นกกระซิบ):** คู่แข่งตรง: นกกระซิบ (AI บนแอปถุงเงินของรัฐ) และ insight ใน Grab / LINE MAN Merchant — ช่วย "ดูยอดขาย" ได้ แต่ Belka ตัวเดียวที่ให้แผนการตลาดพร้อมใช้ + ถามได้ว่าทำไม (Amazon Quick) + guardrail ซื่อสัตย์ (Trust Engine)
2. **🎯 Problem–Solution fit:** สัมภาษณ์จริง 8 ร้าน — แก้ "ร้านเล็กแพ้เพราะการตลาด ไม่ใช่ของไม่ดี" ดึงรายได้กลับในภาวะต้นทุนบีบ [source: user interview]
3. **📈 Impact & Scalability:** ตอบปัญหาชาติ "ต้นทุนบีบรายได้" ตลาด 402,793 ร้าน F&B · เพิ่มรายได้ + ตัดค่าเอเจนซี่ + ดึงออเดอร์มาช่องทางตรงเพื่อลด GP · margin สูง scale ได้ [source: web research]
4. **⚙️ Technical Feasibility:** สร้างบนเครื่องมือสำเร็จรูป (Amazon Quick + API ของ LINE/Meta/Google) · Trust Engine คำนวณด้วยสูตร AI ไม่ยุ่งกับตัวเลข · มีแผนสำรองให้ร้านได้แผนเสมอ
5. **🌱 Sustainability & Viability:** freemium → Profit vault ฿150–1,000/เดือน · ถูกกว่าเอเจนซี่ 15–150 เท่า · วัดผล 3 เดือน + learning loop [source: web research]
6. **💰 งบการตลาดจาก GP ที่ประหยัดได้:** ร้านกรอกราคาขาย + ต้นทุนวัตถุดิบ → Belka หัก GP ตามช่องทางให้ เห็นกำไรจริง · ร้านเล็กประหยัด GP ~1,800฿/เดือน (หน้า 7) → แบ่ง 30% เป็นงบการตลาด ร้านไม่ต้องควักเพิ่ม

> 🏆 สรุป: "นกกระซิบบอกว่าร้านขายได้เท่าไหร่ — Belka บอกว่าต้องทำอะไรต่อ" · คิดกำไรจริงหลังหัก GP · ใช้งบจาก GP ที่ประหยัดได้ · Trust Engine คุมให้ทุกคำแนะนำซื่อสัตย์ต่อลูกค้า

## 04·05 · คู่แข่ง & ป้อมปราการทางธุรกิจ · Competition & Moat

### 🥊 คู่แข่ง · Landscape

**มีคู่แข่งตรง** แต่ยังไม่มีใครส่ง "แผนรายสัปดาห์พร้อมใช้ + เหตุผล" ให้เจ้าของร้านที่ไม่ใช่นักการตลาด

| กลุ่ม | ตัวอย่าง | ให้อะไร (ไม่ใช่แผน) |
|---|---|---|
| 🟧 **ตรง** · AI ผู้ช่วยร้านค้า (ภาครัฐ) | **นกกระซิบ** บนแอปถุงเงิน | วิเคราะห์ยอดขาย ต้นทุน ราคาวัตถุดิบ + สินเชื่อ — ไม่ใช่แผนการตลาด |
| 🟧 **ตรง** · เครื่องมือร้านในแอปเดลิเวอรี | **Grab / LINE MAN Merchant** | รายงานยอดขาย + โฆษณาในแพลตฟอร์ม — ผูกกับช่องทาง GP สูง |
| เอเจนซี่ AI ไทย | SiamScale AI (2025) | บริการ retainer แพง |
| เครื่องมือแพลตฟอร์ม | LINE OA · Meta · Google | ช่องทาง ไม่ใช่แผน |
| เครื่องมือคอนเทนต์ | Canva | ปฏิทินเปล่า สมมติรู้กลยุทธ์ |
| ค้นหาร้านอาหาร | Wongnai (900,000+ ร้าน) | ค้นพบ/รีวิว ไม่วางแผน |

ช่องทางหลักตลาดไทย: LINE 54M MAU · Google Maps 72% เช็กก่อนไปร้าน · Facebook ~86.6% ประชากร [source: web research]

> 🏰 คู่แข่งลอก**ฟีเจอร์**ได้ใน 3–6 เดือน — แต่ลอก **"เวลา"** ไม่ได้ · Data loop + switching cost ที่สะสมเองยิ่งนานยิ่งทิ้งห่าง · **แผนพร้อมใช้ + เหตุผล ✦ มีที่ Belka ที่เดียว**

### 🏰 ทำไมลอกไม่ได้ · Defensibility

ถ้าคู่แข่งลอกทุกอย่าง? ฟีเจอร์ลอกได้ใน 3–6 เดือน แต่ **4 ชั้นนี้ต้องสะสมตามเวลา ลอกไม่ได้**

1. **🔄 Compounding Data Loop** — เก็บ 3 ชั้น: ข้อมูล → นโยบาย → ผลลัพธ์ (measured vs predicted) รู้ว่ากลยุทธ์ไหนเวิร์กกับร้านแบบไหน ยิ่งนานยิ่งทิ้งห่าง
2. **🎯 ระบบนำร่องเฉพาะร้าน** — สูตรเฉพาะร้านปรับทุกสัปดาห์ → switching cost ที่สะสมเอง
3. **🧲 ลูกค้าที่ "ไม่มีเราก็ไม่มี"** — สร้างลูกค้าใหม่ที่ผูกกับร้านผ่านช่องทางที่ Belka สร้าง คู่แข่งมาทีหลังไม่ได้กลุ่มนี้
4. **📊 วัด Loyalty อัตโนมัติ** — repeat rate สะสมเป็นหลักฐานคุณค่า ยิ่งสะสมยิ่งมีค่า

> 🏰 data network effect + switching cost: คู่แข่งลอกฟีเจอร์ได้ แต่ลอก "เวลา" ไม่ได้ — วันที่เขาเปิดตัวเริ่มที่ศูนย์ ส่วน Belka นำไปแล้วหนึ่งปี [source: participant]

## 06 · กลไกลดต้นทุน GP · ใช้ได้จริงไหม?

**จุดยืนซื่อสัตย์:** ยังใช้ Grab/เดลิเวอรีอยู่ (ช่วยหาลูกค้าใหม่) แต่ Belka ดันให้ลูกค้า **อยากมาหน้าร้าน/สั่งตรงเป็นหลัก** (GP=0) → เปลี่ยน **"สัดส่วนช่องทาง"** ไม่ใช่ **"อัตราค่า GP"** [source: participant]

**ตัวอย่างการคำนวณ (สมมติ: ออเดอร์ผ่านแพลตฟอร์ม 80% → 50% หลังใช้ Belka · GP 30% · ยอดขายรวมเท่าเดิม):**

| ขนาดร้าน | ยอดขาย/ด. | ค่า GP ก่อน | ค่า GP หลัง | ประหยัด/ด. | ประหยัด/ปี |
|---|---|---|---|---|---|
| ร้านเล็ก (100 ออเดอร์ × 200฿) | 20,000฿ | 4,800฿ | 3,000฿ | **1,800฿** | 21,600฿ |
| ร้านกลาง (300 ออเดอร์ × 250฿) | 75,000฿ | 18,000฿ | 11,250฿ | **6,750฿** | 81,000฿ |

**ค่า GP:** ตารางใช้ GP 30% (เพดาน) · อัตราโปรฯ Grab 9% / LINE MAN 15% / ShopeeFood 13% เป็นอัตราแบบมีเงื่อนไข — **ในแอปร้านแก้ GP% ของตัวเองได้** [source: web research]

**กำไรจริงต่อออเดอร์ — ต้นทุนวัตถุดิบ ≠ GP:** ออเดอร์ 200฿ · ต้นทุนวัตถุดิบ 80฿ (ตัวอย่าง 40%) · ผ่าน Grab: 200 − 80 − GP 60 = กำไร 60฿ · สั่งตรง/หน้าร้าน: 200 − 80 − 0 = กำไร 120฿ · **ออเดอร์เดียวกัน สั่งตรงได้กำไร 2 เท่า**

**กำไรสุทธิร้านเล็ก:** ประหยัด GP 1,800฿ − ค่า Belka 1,000฿ = **+800฿/เดือน** → แนะนำแบ่ง **30%** เป็นงบการตลาด (วัดด้วย S7)

**บทบาท:** แพลตฟอร์ม = หาลูกค้าใหม่ · หน้าร้าน = ลูกค้าซ้ำ (กำไร) · **ข้อจำกัด:** last-mile จัดเอง, ยังไม่รวมค่าส่งหากร้านส่งเอง, ลูกค้าบางส่วนติดแอป → เคลม "ลดการพึ่งพา" ไม่ใช่ "เลิกใช้" [source: participant + web research]

## 10 · ผังการใช้งาน · User Flow

เปิดแอป → Onboarding 5 ขั้น (การ์ดแตะเลือก ไม่บังคับกรอกต้นทุน) → วิเคราะห์ลูกค้าจำลอง (persona ติดป้าย "Simulated") → แผนสัปดาห์ ~10 นาที/วัน → แคปชัน + "ทำไมต้องทำ?" → ตรวจ red-line/message gate (ถ้าพบ → เตือน + เสนอคำปลอดภัย / ถ้าผ่าน → guided posting) → วัดผล → learning loop วนกลับไปปรับ "แผนสัปดาห์" ให้ดีขึ้นทุกสัปดาห์ [source: แผนออกแบบระบบของทีม]

| ความเสี่ยง | การรับมือ |
