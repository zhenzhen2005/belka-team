# Product — Belka

> แหล่งข้อมูล: docs/submission.md · ข้อความที่ไม่มีใน submission.md และเป็นสิ่งที่ Kiro สันนิษฐานเอง ติดป้าย "(assumption)"

## ภาพรวม
Belka คือผู้ช่วยการตลาด AI บนมือถือสำหรับร้าน SME ไทย กลุ่มแรกคือร้านอาหาร เบเกอรี่ เครื่องดื่ม
ส่งแผนการตลาดรายสัปดาห์พร้อมใช้ ใช้เวลาประมาณ 5–10 นาทีต่อวัน
แก้ภาวะ "ต้นทุนบีบรายได้" โดยดันฝั่งรายได้ที่ร้านคุมเองได้ และลดต้นทุนที่คุมได้ (ค่าเอเจนซี่ ค่า GP แพลตฟอร์ม)

หลักการ: **"Belka เสนอ เจ้าของร้านตัดสินใจ"** (assumption: ถอดความจากหลักการ "ใช้ง่าย ซื่อสัตย์ เจ้าของร้านอยู่ในลูป" ในเอกสาร ไม่ใช่ประโยคต้นฉบับ)

Pillar: SME & Local Economy · Tagline: เพื่อนคู่คิด SME

## ปัญหา
- ดัชนีรายได้ SME Q2/2568 ลด 1.11% ขณะต้นทุนเพิ่ม 4.16% (แหล่ง: participant)
- สัมภาษณ์ 8 ร้านใน กทม./นนทบุรี: ปัญหาหลักคือ "ไม่รู้ว่าจะทำการตลาดอย่างไร"
  - ไม่รู้จะสร้างคอนเทนต์อะไร
  - ไม่รู้ว่าควรใช้ช่องทางไหน
  - ไม่รู้ว่าควรโพสต์เมื่อไรและบ่อยแค่ไหน
  - เขียนแคปชันและทำสื่อไม่เป็น
  - เวลาน้อย วางแผนให้ทำได้จริงไม่ได้
  - กลัวดูเหมือนหลอกลูกค้า
- ค่า GP แพลตฟอร์มเดลิเวอรีสูงถึง ~30% ค่าเอเจนซี่ ฿15,000–150,000 ต่อเดือน (แหล่ง: web research)

## ผู้ใช้เป้าหมาย
- เจ้าของร้าน SME ที่ไม่มีทีมการตลาด ไม่มีความรู้ และไม่มีงบการตลาด
- ใช้มือถือ ภาษาไทยเป็นหลัก (assumption: ภาษาเอกสารยืนยันว่าสองภาษา ไทย/อังกฤษ แต่ผู้ใช้ปลายทางเป็นคนไทย)
- กลุ่มแรก: ร้านอาหาร เบเกอรี่ เครื่องดื่ม (ยืนยันแล้ว A1)

## วิธีแก้
ขั้นตอน 5 สเต็ป: เข้าใจร้าน → ลูกค้าจำลอง → แผนพร้อมใช้ (อะไร/ทำไม/ช่องทาง/เมื่อไร + แคปชัน) → เลือกช่องทาง → วัดผลและปรับ
- ฝั่งรายได้: แผนพร้อมใช้, "ถาม Belka", ปุ่ม "ทำไมต้องทำ?", ดันช่องทางที่ร้านเป็นเจ้าของ (LINE/เพจ)
- ฝั่งต้นทุน: ตัดค่าเอเจนซี่, ลดการพึ่งแพลตฟอร์ม GP สูง, คำนวณกำไรต่อเมนูแยกช่องทาง, แนะนำงบการตลาดจาก GP ที่ประหยัดได้ (แบ่ง 30%)
- กรอกต้นทุน 3 ระดับ (ไม่บังคับ): ① เลือกช่วงกำไร 🟢🟡🔴 ② ต้นทุนวัตถุดิบ 1 ช่องต่อเมนู ③ ค่ามาตรฐาน F&B ติดป้าย "ค่าประมาณ — แก้ได้"

## ขอบเขต (MoSCoW)
- **Must (P0):** Onboarding 5 ขั้น · นำเข้าเมนู OCR/Maps · แผนสัปดาห์ ~3 งาน · ปุ่ม "ทำไมต้องทำ?" · red-line/message gate · ถาม Belka
- **Should (P1):** persona Simulated · Profit vault + Promo · ป้าย/QR · วัดผล + learning loop · กำไรแยกช่องทาง + งบการตลาดจาก GP
- **Could (P2):** guided posting LINE/Meta · เทมเพลต Canva · หลายภาษา
- **Won't (เฟสแรก):** auto-posting เต็มรูปแบบ · ร้านหลายสาขา · ยิงแอดอัตโนมัติ (Belka แนะนำงบเท่านั้น) · POS/สต็อก

## Bootcamp must-have feature
**แผนสัปดาห์พร้อมแคปชันและเหตุผล** (จาก P0 "แผนสัปดาห์ ~3 งาน" + "ทำไมต้องทำ?" + red-line/message gate ใน docs/submission.md)
เลือกเพราะแก้ปัญหาหลักของ Belka รันได้ด้วยโปรไฟล์ร้านจำลอง 1-2 ร้าน และทำงานได้ด้วยตัวเองโดยไม่ต้องรอ OCR หรือแชตบอต
ขอบเขตสำหรับ 3 ชั่วโมง: agent (Strands + Amazon Bedrock) ร่างงาน 3 งานพร้อมแคปชันไทยและเหตุผลของแต่ละงาน, red-line gate ตรวจแคปชันด้วยโค้ดก่อนแสดง, เจ้าของร้านกดยืนยันหรือข้าม ("Belka เสนอ เจ้าของร้านตัดสินใจ"), ถ้า Bedrock ตอบไม่ได้ให้ใช้แผนสำรองจาก Trust Engine (ความเสี่ยง R1)
ข้อมูลและบริการภายนอกใช้ข้อมูลจำลองและ stub เท่านั้น ส่วน "ถาม Belka" ทำภายหลังเป็น Strands agent บน Bedrock ไม่ใช้ Amazon Quick
